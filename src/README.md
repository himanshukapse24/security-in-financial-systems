# Secure Financial Security Framework (DCU Practicum 2026)

## Overview
This research practicum implements a secure data-processing framework in **Java 17** to ensure data trustworthiness, traceability (RQ1), and assess machine-learning resilience under synthetic anomaly injections (RQ2).

## Tech Stack
- **Language:** Java 17+
- **Build Tool:** Maven
- **Cryptography Library:** BouncyCastle
- **Machine Learning Engine:** WEKA
- **Dataset Ingestion:** Apache Commons CSV
